# 🎮 Pokémon Leaf Green Recreation (Unity Fan Project)

This is a **fan-made recreation** of Pokémon Leaf Green built in **Unity**, aimed at learning and practicing game development principles like object-oriented design, UI programming, and gameplay systems.

---

## 🧩 Key Features

- **Starter Selection**  
  - Choose your starter Pokémon before starting the game.
  - You can change the available generation range (Gen 1 - Gen 9) directly in the Unity Inspector.
  
- **Multi-Generation Support**  
  - Expand your starter choices beyond the original Kanto starters!

- **Core Gameplay Systems**  
  - Basic overworld movement
  - Inventory system
  - Simplified stats and leveling systems

---

## 🚧 Missing Features (Planned or Future Work)

- **Battle Mechanics**  
  - Turn-based battle system, move selection, type advantages, status effects.

- **Music and Audio**  
  - Background music, sound effects, and battle sounds.

- **Story and Dialogue**  
  - NPC interactions, event scripting, and storyline progression.

---

## 🛠️ Built With

- **Engine**: Unity  
- **Language**: C#  
- **Version Control**: Git + GitHub

---

## 📚 Learning Goals

This project is helping develop skills in:

- Scriptable Objects and data-driven design
- Unity's UI Toolkit and scene management
- Game architecture for scalable development
- Handling large datasets (Pokédex data, move lists, etc.)
